# 🧮 Calculatrice Java

Mon premier projet en **Java** réalisé dans le cadre de mon apprentissage de la programmation.

Ce projet permet de pratiquer les notions de base de Java à travers un menu interactif.

### Fonctionnalités

* Addition de deux entiers
* Multiplication de deux entiers
* Calcul de la moyenne d'un tableau
* Recherche du nombre maximum dans un tableau
* Menu interactif avec `switch`
* Saisie des données avec `Scanner`

### Notions utilisées

* Variables et types de données
* Méthodes
* Tableaux
* Boucles `for` et `do...while`
* `switch / case`
* Conditions `if`
* Classe `Scanner`
